# Cool Battery — Rebranding Estratégico

Presentación comercial (15 diapositivas) para la propuesta de rebranding y estandarización de marca de Cool Battery.

## Cómo verla

1. Descarga los 3 archivos: `index.html`, `styles.css`, `slides.css` (deben estar en la misma carpeta).
2. Abre `index.html` en tu navegador (Chrome o Edge recomendado).
3. Verás las 15 diapositivas en formato 16:9, apiladas para hacer scroll.

## Cómo exportar a PDF

1. Abre `index.html` en Chrome o Edge.
2. Presiona `Ctrl + P` (o `Cmd + P` en Mac).
3. Configura:
   - Destino: Guardar como PDF
   - Diseño: Horizontal
   - Márgenes: Ninguno
   - Escala: 100%
   - Gráficos de fondo: **Activado** (importante para los colores)
4. Guarda el archivo.

## Sistema de diseño

- **Tipografía de títulos:** Montserrat (peso 700–900)
- **Tipografía de cuerpo:** Red Hat Display (peso 300–700 según jerarquía)
- **Paleta:** Verde (#1c8f45), negro, amarillo (#f4c81a) — inspirada en el logo de Cool Battery
- **Iconografía:** familia custom de 18 íconos SVG con motivo de batería/energía, inline en `index.html`
